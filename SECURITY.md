# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the following versions of **Haki FMCG**:

| Version | Supported          | Security Status |
| ------- | ------------------ | --------------- |
| 2.0.x   | :white_check_mark: | Actively supported |
| 1.x     | :x:                | End of life     |

---

## Reporting a Vulnerability

The Haki FMCG team takes security vulnerabilities seriously. If you discover a security issue or vulnerability within this platform, please report it promptly.

### How to Report
1. **Email**: Send detailed disclosure reports to `security@hakifmcg.com` (or open a confidential security advisory on GitHub).
2. **Details to Include**:
   - Component / API endpoint affected
   - Step-by-step reproduction instructions or Proof of Concept (PoC)
   - Estimated impact and severity rating (CVSS if available)
   - Proposed mitigation or patch if identified

### Response Timeline
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Assessment**: Within 48 hours.
- **Resolution & Patch Deployment**: Critical issues patched within 5 business days.

Please refrain from publicly disclosing the issue until our engineering team has developed and released a remediation patch.
